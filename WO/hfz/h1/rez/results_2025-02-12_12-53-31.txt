Here is a simple example of how you can do this in Rust:

```rust
use reqwest;
use serde_json::Value;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let url = "https://api.example.com/users";
    let headers = [
        ("Content-Type", "application/json"),
        ("Authorization", "Bearer YOUR_API_KEY"),
    ];

    let response = reqwest::get(url, headers)?;

    let data: Value = response.json()?;

    let mut output = String::new();

    for user in data["data"].as_array() {
        let user_data = user.as_object()?;

        output.push_str(&format!("User ID: {}\n", user["id"]));
        output.push_str(&format!("Name: {}\n", user["name"]));
        output.push_str(&format!("Email: {}\n", user["email"]));
        output.push_str(&format!("Phone: {}\n", user["phone"]));
        output.push_str(&format!("Address:\nStreet: {}\nCity: {}\nState: {}\nZip: {}\n", user["address"]["street"], user["address"]["city"], user["address"]["state"], user["address"]["zip"]));
        output.push_str("\n\n");
    }

    println!("{}", output);

    Ok(())
}
```

This code sends a GET request to the specified API URL, parses the JSON response, and then iterates over the user data. It prints out the user's ID, name, email, phone number, and address. The output is formatted to make it easier to read.

Note that you'll need to replace `YOUR_API_KEY` with your actual API key. Also, this code assumes that the API returns the data in the same format as the example JSON response. If the API returns the data in a different format, you'll need to adjust the code accordingly.
